# 🔍 Learning How to Learn Cyber Security

## 📌 Introduction
A quick Google search for **“learn cyber security”** returns hundreds of millions of results, while **“learn hacking”** returns even more. With this overwhelming amount of information, learners face a choice:

- Accept the first few results they see  
- Or develop **strong search and evaluation skills** to find reliable, accurate information  

This lesson focuses on building those essential skills.

---

## 🎯 Learning Objectives
By the end of this lesson, learners should be able to:

- Evaluate information sources critically  
- Use search engines efficiently  
- Explore specialized search engines  
- Read and understand technical documentation  
- Use social media responsibly for learning  
- Stay informed using reliable news outlets  

---

## 🧠 Evaluating Information Online
Anyone can publish content online—blogs, articles, social media posts, or wiki edits. This makes it essential to **evaluate information carefully**.

### Key Factors to Consider

#### 🏷️ Source
- Identify the author or organization  
- Check credibility and expertise  
- Publishing content does not automatically make someone an authority  

#### 📊 Evidence and Reasoning
- Look for verifiable facts and solid arguments  
- Avoid unsupported opinions and speculation  

#### ⚖️ Objectivity and Bias
- Assess whether information is presented impartially  
- Be cautious of content promoting hidden agendas  

#### 🔎 Corroboration and Consistency
- Cross-check claims with multiple independent sources  
- Reliable information is usually supported by consensus

## 🔎 Using Search Engines Effectively

Common search engines include:
- Google  
- Bing  
- DuckDuckGo  

Most search engines support **advanced search operators**.

### Useful Google Search Operators

- `"exact phrase"`  
  - Finds pages containing the exact wording  
  - Example: `"passive reconnaissance"`

- `site:`  
  - Limits results to a specific domain  
  - Example: `site:tryhackme.com success stories`

- `-` (minus sign)  
  - Excludes specific words  
  - Example: `pyramids -tourism`

- `filetype:`  
  - Finds specific file formats (PDF, DOC, XLS, PPT)  
  - Example: `filetype:ppt cyber security`

## 🧭 Specialized Search Engines

### 🌐 Shodan
- Searches Internet-connected devices  
- Finds servers, routers, IoT devices, and industrial systems  
- Example use: identifying servers running outdated software  

### 🌐 Censys
- Focuses on Internet-connected hosts, websites, and certificates  
- Useful for:
  - Asset discovery  
  - Open port auditing  
  - Identifying rogue systems  

### 🦠 VirusTotal
- Scans files, URLs, and hashes using multiple antivirus engines  
- Provides community insights and detection history  

### 🔐 Have I Been Pwned (HIBP)
- Checks if an email address appears in data breaches  
- Highlights risks of password reuse

## 🐞 Vulnerabilities and Exploits

### 📖 CVE (Common Vulnerabilities and Exposures)
- A standardized system for identifying vulnerabilities  
- Each vulnerability has a unique ID (e.g., CVE-2024-29988)  
- Maintained by MITRE  
- Searchable via:
  - CVE Program website  
  - National Vulnerability Database (NVD)  

### 💥 Exploit Database
- Repository of public exploit code  
- Used for authorized security testing  
- Some exploits are verified and tested  

### 🧑‍💻 GitHub
- Hosts proof-of-concept (PoC) and exploit code  
- Valuable for research and defensive understanding  

⚠️ Exploitation should only be performed with **explicit permission**.

## 🌐 Social Media and Cyber Security
Social media platforms host billions of users and vast amounts of information.

### 🔑 Benefits for Cyber Security Professionals
- Follow experts, organizations, and communities
- Stay updated on trends, tools, and vulnerabilities

### ⚠️ Security Awareness
- Oversharing can expose sensitive personal information
- Answers to security questions may be visible publicly
- Attackers can exploit this for account takeover

### 🧪 Safe Exploration Tip
- Use temporary email addresses when exploring new platforms
- Avoid linking experimental accounts to real identities
